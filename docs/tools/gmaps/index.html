Google 地圖更新進度

各停車場在 Google 地圖上的名稱要以「大日」或「千斗」開頭，網站欄位要填官網該場的專屬連結。按「狀態更新」只會重新讀取還沒更新的場站。

Google API 金鑰設定

讀取 Google 地圖資料需要一組 Google Maps Platform 的 API 金鑰。金鑰只存在這台電腦的瀏覽器裡，不會上傳到網站。

  1. Google Cloud Console 建立專案並啟用計費（每月有免費額度）。
  2. 啟用「Maps JavaScript API」與「Places API (New)」。
  3. 建立 API 金鑰，應用程式限制選「網站」，填 https://www.dari.com.tw/tools/*；API 限制只勾上面兩個。
